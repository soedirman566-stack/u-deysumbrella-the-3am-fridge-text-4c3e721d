# The 3AM Fridge Text

A make.fun entry for **The 3AM Fridge Text**. `main.ts` (Node 22, TypeScript run directly, no dependencies) writes a single line to `/output/entry.txt`: the one text a smart fridge sends its owner at 3am — a deadpan little machine that has been counting the night's visits and has opinions about them. An optional `argv[2]` overrides the output path for local testing.
